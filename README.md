# ASK2 - 毎日の市場分析と漫画

毎日の市場分析と漫画を記録するカレンダーアプリです。

## 機能

- 📅 **カレンダー表示**: 月単位での日付表示
- 📝 **データ記録**: ASK1要約・市場分析・漫画画像を保存
- 📥 **JSON インポート**: 前月のデータをインポート
- 📊 **CSV エクスポート**: 月別データを CSV 形式で出力
- 🔄 **複数タブ同期**: 他のタブでのデータ変更をリアルタイム同期
- 🌓 **ダークモード**: OS の設定に自動追従
- 📱 **レスポンシブ**: モバイル・タブレット・デスクトップ対応
- ♿ **アクセシビリティ**: ARIA ラベル・キーボード操作対応
- 💾 **PWA 対応**: インストール可能・オフライン対応

## 操作方法

### キーボードショートカット
- `Ctrl+Enter`: モーダル内でのデータ保存
- `Escape`: モーダルを閉じる
- `Ctrl+Z`: 操作を戻す（アンドゥ）
- `Tab`: 要素間の移動
- `Enter`: ボタンの実行

### ボタン
- **← 前月 / 翌月 →**: 月の移動
- **📥 (Export)**: JSON 形式でデータをダウンロード
- **📤 (Import)**: JSON ファイルから データをインポート
- **📊 (Report)**: 月別の入力統計を表示
- **クリア**: 入力フィールドをすべてクリア
- **保存**: データを保存

### マウス操作
- 日付をクリック: 詳細エディタを開く
- ドラッグ&ドロップ: 画像をアップロード

## データ保存

すべてのデータは ブラウザの `localStorage` に保存されます。
- 自動保存: 「保存」ボタン押下時
- データ形式: JSON（localStorage 内）
- エクスポート形式: JSON・CSV

## 動作環境

- ブラウザ: Chrome, Firefox, Safari, Edge
- OS: Windows, macOS, Linux, iOS, Android
- ネットワーク: インターネット接続必須（初回ロード時）

## PWA インストール

1. ブラウザのアドレスバーの右側のアイコンをクリック
2. 「アプリをインストール」を選択
3. ホーム画面に追加

## プライバシー

- すべてのデータはローカルに保存
- サーバーへの送信なし
- ブラウザのキャッシュクリアでデータ削除
