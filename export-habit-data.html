📅 習慣データエクスポート

このページは habit.html の localStorage データを JSON ファイルにエクスポートします。

用途：habit-cycle.py での自動分析に必要です。毎分自動実行が設定されている場合は、このページをブラウザで開き続ける必要があります。

エクスポート方法

  1. 下のボタンをクリック → habit-data.json が同じディレクトリに保存されます
  2. 繰り返し実行可能（上書きされます）
  3. ブラウザ開発者ツール → Application → Local Storage でも手動確認可

詳細

habit.html の localStorage キー: habit_data

出力ファイル: habit-data.json （このディレクトリ）

形式:

{
  "habits": [
    {
      "id": "h_123456",
      "name": "朝ラン",
      "log": {
        "2026-06-19": true,
        "2026-06-18": true
      }
    }
  ]
}
